# Make the AI Judge Laugh: Cat Reviews Its Human — entry

Entry for the make.fun competition [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) (slug `u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990`).

A Python program that writes one line (at most 200 characters) — a
one-star review written by a house cat about the human it lives with —
to /output/entry.txt. Standard library only, no network.
